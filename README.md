# FrontEndTP1 — Landing de Portafolio Personal

Desarrollo de Sistemas Web (Front End) - 2° A

## Descripción

Landing page personal creada para la PFO1, que presenta mi perfil como estudiante
de Desarrollo de Software, mis habilidades, mi experiencia  y
una forma de contacto. Desarrollada con HTML semántico y CSS.

https://front-end-tp-1.vercel.app

## Decisiones de diseño

- Elegí una paleta de colores azul y amarillo por que soy de boquita.
- Usé las tipografías Space Grotesk (títulos) e Inter (texto) desde Google Fonts.
- Organicé las habilidades con CSS Grid en tarjetas, y usé Flexbox para la
  navegación, el formulario y los links de redes.
- Agregué transiciones suaves en botones y
  tarjetas al pasar el mouse, para mejorar la experiencia visual.
- Incluí una sección personal sobre mi experiencia, ya que
  considero que es relevante respecto al desarrollo de software.
- El diseño es responsive: se adapta a pantallas chicas ajustando la navegación
  y los espaciados.
